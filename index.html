一条命令，
跑在你自己的机器上。

CaseFlow 是 Apache 2.0 开源自部署。用例、知识库、模型 Key 都在你的环境里；AI 能力可选，不配置也能用脑图与执行。

  • Docker Compose 启动 case-server、MySQL、Qdrant 与反向代理
  • 首次启动自动导入初始化数据与内置管理员
  • 许可证 Apache 2.0，可审计、可修改、可私有部署

部署之前，
先把问题问完。

下面是你自部署前最常确认的几件事。更多细节在仓库 README 和部署文档里。

去 GitHub 提问
支持 XMind 吗？

支持 XMind 与 XMind Zen 格式的导入和导出。团队原有的脑图可以直接带进来，也可以把 CaseFlow 里的用例导回 XMind。

必须接 AI 吗？

不必须。脑图编辑、实时协作、执行追踪和知识库都可以独立使用。AI 供应商、模型、温度和系统提示词在管理页配置，接口兼容 OpenAI 规范即可。

数据存在哪里？

自部署模式下，用例和执行数据在 MySQL，知识库向量在 Qdrant，两者都在你的服务器。文档解析可接阿里云 DashScope，也可以不启用。

多人协作怎么同步？

基于 Netty-socketio 的房间模型：同一用例集内的客户端实时接收编辑广播，支持房间锁、在线成员状态、保存快照和断线自动保存。

许可证是什么？

Apache 2.0。可以内部部署、修改和分发；具体条款见仓库根目录的 LICENSE 文件。
